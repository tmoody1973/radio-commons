# 60-second setup video script

For Tarik to screen-record on a computer. Record after Clerk's automatic ChatGPT registration (CIMD) is on, so there are no client ID or secret fields to show. Use a test ChatGPT account, or blur your name and email in the corner.

**Setup before recording:** browser window at about 1280×800, zoomed to 110%, ChatGPT signed in, the setup page (https://radio-commons.vercel.app/beta) open in a second tab, notifications off.

| Time | On screen | Voice-over |
|---|---|---|
| 0:00–0:05 | The Radio Milwaukee station home card in ChatGPT, music playing | "This is Radio Milwaukee, inside ChatGPT. Here's how to set it up." |
| 0:05–0:12 | chatgpt.com/plugins, click **Add**, then **Add custom MCP server** | "Go to chatgpt.com slash plugins. Click Add, then Add custom MCP server." |
| 0:12–0:20 | Type the name, upload the icon | "Name it Radio Milwaukee. You can add our icon from the setup page." |
| 0:20–0:28 | Setup page: click **Copy**; ChatGPT: paste into Server URL; Authentication shows OAuth | "Copy the address from our setup page and paste it in. Leave the sign-in set to OAuth." |
| 0:28–0:35 | Tick **I understand and want to continue** | "ChatGPT shows this warning for any plugin that isn't in its directory yet. Tick the box." |
| 0:35–0:45 | **Create as a plugin**, the Radio Milwaukee sign-in, **Allow** | "Click Create, sign in to Radio Milwaukee, and choose Allow." |
| 0:45–0:55 | New chat: type "@Radio Milwaukee open the station home"; the home card appears; tap **Listen live** | "Now start a chat with at Radio Milwaukee. Open the station home and tap Listen live." |
| 0:55–1:00 | The home card, with **Send feedback** highlighted | "It's a beta, so tell us what you think. Just say: send feedback." |

Export at 1080p as MP4. Keep it under 60 seconds so it plays inline in email and on social media. Add captions; most people watch muted.
