# Radio Commons slice 4: events — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Alexa answers "what's on near there tonight?", "what's on" by time/type, and "what is Radio Milwaukee recommending?" from the MKE Field Guide, with map and carousel cards and an Add to calendar action.

**Architecture:** The Field Guide (~/Projects/mke-field-guide, Next.js + Neon Postgres via Drizzle) gains two read-only JSON routes reusing its search, time windows, venue coordinates (own pin, else Overture registry) and calendar links. A one-time script fills missing venue pins with Amazon Location. Radio Commons gains a validated client, two MCP tools and two card views (events map, events carousel) in the existing Alexa+ card system.

**Tech Stack:** Field Guide: Next.js route handlers, Drizzle, PGlite tests (`tests/helpers/test-db.ts` `createTestDb()`), Vitest. Radio Commons: mcp-handler, ext-apps, zod, Vitest. Amazon Location (geo-places SearchText, stored use) via Tarik's `aws login` session.

**Spec:** `docs/superpowers/specs/2026-10-03-events-design.md` (approved 2026-10-03, with measured coverage and added decisions).

## Global Constraints

- Only upcoming, scheduled instances of scheduled events; never cancelled/postponed/past.
- Public routes return only fields already shown on the public site; max 10 results; unknown query parameters → 400; `cache-control: public, s-maxage=300`.
- "Near": 1 mile from the chosen story place, widen once to 3 miles and say so. The model never passes coordinates.
- Picks: staff picks in the curator's words, topped up with upcoming station events to 3.
- Speech: up to 3, numbered like the screen, venue + day/time each; "from Radio Milwaukee's event guide".
- Cards: Amazon Map (near) and Carousel (otherwise) patterns, existing tokens/scale/light-dark; every event: Add to calendar (Google link via openLink) and Details (Field Guide page).
- Geocoding writes only empty `venues.lat/lng` where the registry has no coordinates; confidence-checked; dry run first, listed to Tarik before any write (PROD write).
- PROD steps need Tarik's go-ahead: the geocoding write, Field Guide production deploy, Radio Commons production deploy.

## Review Focus

1. **An event whose venue has no coordinates in a "near" query.** Expected: excluded from near results, still found by non-near queries. Test: Task 1 "near skips venues without coordinates".
2. **Recurring events with many instances** ("tonight" must use the instance tonight, not the series' first date). Expected: the instance inside the window. Test: Task 1 "picks the instance inside the window".
3. **Late-night windows across midnight** (an 11:30 PM show "tonight"). Expected: included by `presetWindow('tonight')`. Test: Task 1.
4. **Text in event titles/venues with markup** reaching cards and speech. Expected: escaped. Test: Task 5 card escaping.
5. **Field Guide slow or down mid-turn.** Expected: the event-guide apology, no partial card. Test: Task 4/5.
